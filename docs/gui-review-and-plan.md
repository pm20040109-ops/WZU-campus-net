# GUI 审查与重构方案

日期：2026-09-23。基线：`7576169fc1e748b42f22460f253464a3b09cbc81`（`feature/traffic-stats`）。

## 审查结论

现有认证、网络识别和流量统计已有模块划分，68 项现有回归测试通过。GUI 的主要问题是可读性、控件尺寸、信息层级和状态反馈；可以保留标准库与 Tkinter 路线，重构界面层，无需引入重量级浏览器运行时。

审查使用实际 Tk 窗口、150% 系统缩放和虚构数据，检查全部五页，以及 820×600 逻辑像素下的流量/网络页。没有读取真实账号密码，没有向学校发送请求。以下将复现缺陷与体验建议区分列出。

| 优先级 | 已确认的问题 | 基线位置 | 影响与建议 |
|---|---|---|---|
| P2 | 保存失败未捕获 | `campus_gui.py:1557,1589,1598` | 模拟只读目录后抛出 PermissionError，未出现失败对话框。统一保存入口，在页内显示成功/失败并保留输入。 |
| P2 | 离开校园网保留旧身份 | `campus_gui.py:1028` | 显示“等待校园网”时仍呈现之前的账号、IP、MAC。清空失效快照并给出下一步操作。 |
| P2 | 错误日志被标为成功 | `campus_gui.py:960` | “登录未成功: 账号或密码错误”包含“成功”，实际应用绿色 `ok` 标签。错误词优先，结果使用明确语义。 |
| P2 | 导航不能键盘操作 | `campus_gui.py:536` | 导航是不可聚焦 Frame/Label，只有鼠标绑定。改为可聚焦按钮，支持 Tab、Enter 和快捷切页。 |
| P3 | 刷新销毁流量表选择 | `campus_gui.py:1279` | 选择某一行后再次采样，selection 变为空。按日期更新行，保持选择与滚动位置。 |

视觉审查：默认 880×660 的信息密度偏高；在 820×600 下，流量明细区只容纳约一行。9–10pt 正文/说明混排，常规中文与加粗标题观感差异明显；深色侧栏、蓝色登录、红色注销、青色守护和深色日志同时抢占注意力。输入框、原生小勾选框缺少一致的点击高度。账号、路径、协议字段占据主要界面，下一步操作不突出。此轮没有发现默认大小下所有页面控件普遍被裁切，不能把个人不喜欢的视觉风格笼统当成功能错误。

## 设计方向

采用浅色工作台：雾白背景、白色卡片、青绿色主操作、深墨色文字、柔和分隔线。危险操作使用次级按钮与确认反馈。保留五页导航，让现有用户能找到功能。

字体优先使用本机已有的 Noto Sans SC，缺失时选用微软雅黑 UI / 系统无衬线字体。统一字体对象与字号，避免频繁粗体和低对比细字。窗口与字体按 DPI 一起缩放，使用当前显示器工作区约束窗口。

| 页面 | 重构内容 |
|---|---|
| 连接总览 | 状态主卡、清晰的原因与下一步操作；账号/IP 等连接信息；登录/断开/自动重连；今日/本月用量入口；浅色运行记录。 |
| 流量统计 | 三张大数字汇总卡；每日明细优先占用空间；采样状态与刷新反馈；服务端参考信息折叠；日期稳定更新。 |
| 账号设置 | 大输入框、可触达的密码显示控件；清楚的运营商选择；未保存/成功/失败反馈；首次运行提供设置入口。 |
| 网络设置 | 服务器、校园网名称、超时/采样设置分组；字段解释使用用户语言；错误定位到具体字段。 |
| 自动化 | 大尺寸开关行；分别说明启动时行为与当前守护状态；保存成功说明生效时机；配置路径放入可复制的详情。 |

## 验收目标

1. 默认 1180×800 逻辑像素，屏幕工作区不足时缩小；最小窗口仍能访问全部页面和保存操作。
2. 正文 12pt，说明至少 10pt；中文优先选择清楚的无衬线字体，标题与数字有明确层级。
3. 主要按钮和输入区域至少 44 逻辑像素高；开关行至少 56px，指示图形至少 24px；缩放一起生效。
4. 五页内容有一致的间距；长提示、路径不截断；小窗口支持滚动。
5. 导航支持键盘；保存失败可见；身份过期会清理；失败文案不显示成功色；采样刷新不打断表格选择。
6. 通过既有业务回归、新增关键交互测试和实际 Tk 渲染检查；验证 100%、150%、200% 的布局及小窗口。
7. 整理现有 Git 仓库，补充贡献指南、许可证状态、开发/构建说明、CI 与问题模板；公开文档使用演示数据，保留本地私有配置的忽略规则。

## 实施边界

界面与业务逻辑分离为独立模块。继续使用 Python 标准库运行。开发验证使用离线演示和独立构建产物，避免正在运行的客户端与实际配置受到影响。远端发布地址尚未提供，本轮完成本地仓库准备。
