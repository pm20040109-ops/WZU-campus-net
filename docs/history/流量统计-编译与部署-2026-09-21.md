## 需要留意的两点

1. **exe 模式与脚本模式的统计文件是分开的**：`TrafficMeter` 的路径规则与
   `campus_login.json` 相同（取 exe/源码所在目录）。常驻的 exe 记的是
   `dist\campus_traffic.json`，而 `python campus_login.py traffic` 查的是源码目录那份，
   两者互不相通。已在 README 中写明。
2. **服务端会话的上下行字节恒为 0**：这是服务端未上报该字段，不是采集失败；
   有效数字来自本机网卡计数器。学校登录页的「已用流量」同样显示 0。
