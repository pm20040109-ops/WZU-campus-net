# 修复与部署记录

版本：`2026.09.21.1`。

## 完成内容

- 修复审查报告中的七项问题：注销/登录竞态、GUI 异常后按钮无法恢复、托盘添加失败导致窗口消失、CLI 守护覆盖参数丢失、联网探测误判、纯 JSON 含括号解析错误、MD5 非 BMP 字符兼容错误。
- 登录和注销共用认证锁。注销取消自动登录、守护和手动登录任务，等待已有认证结束后才执行注销；网络请求返回后和重试前检查取消状态。
- 新增 Windows 本地网络检查：必须有可用 IPv4 路由、有效本机地址，且通往认证服务器的接口对应 `campus_networks` 中的网络配置名。默认 `WZXY-Student`，与本机当前校园网一致。
- 自动登录等待校园网就绪，不消耗登录次数。其他网络或 Wi-Fi 未就绪时只检查本机网络状态；守护和 GUI 定时刷新不请求校园网接口。网络识别失败时暂停认证。
- 凭据提交前再次检查网络，HTTP 连接绑定到所选本机源地址；认证状态必须符合 Dr.COM 响应结构。
- 同时启用启动自动登录和自动守护时，由守护统一负责首次认证。
- 构建脚本增加依赖与回归测试检查；新增离线 exe 冒烟测试入口。
